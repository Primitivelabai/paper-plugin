# primitive paper

This extension connects you to primitive paper, a hosted workspace where people and agents build docs, slides, canvases, sites, forms and floor plans side by side. Everything in paper is markdown.

- Sign in once through the browser when Gemini CLI prompts (run `/mcp auth paper` if it doesn't). No API keys.
- Start with the `getting-started` skill when someone first connects or asks what paper can do.
- Use the `work-together` skill before you create, edit, move, rename or undo anything. Changes arrive as suggestions the person approves, and every change can be undone.
- Never apply changes the person hasn't approved.

Made by primitive ai, a boutique AI lab in Perth.
